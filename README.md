# 日语拾阶 · JPLearn

面向日语原版阅读的原生 iOS 训练应用。离线学习，逐项保存，使用系统日语朗读；最低系统为 iOS 15.5。

[GitHub 仓库](https://github.com/CJY-C/jplearn) · [版本与 IPA 下载](https://github.com/CJY-C/jplearn/releases) · [构建记录](https://github.com/CJY-C/jplearn/actions/workflows/build.yml)

0.19.0 课程包共有 614 个单元、3,369 个词汇根，另有 13 个追加义项、279 个知识点、4,885 道词句练习、290 篇阅读，以及 6 个入门诊断模块。N5、N4 均达到本项目数量与结构门槛。N3 现有 1,352 词、115 个知识点、110 篇阅读（含 22 篇独立检测），语法清单覆盖 79 / 101 项。分级为非官方阅读学习次序，材料尚未独立日语审校。完整 N5–N2 目标仍为 6,000 词、400 个知识点、440 篇阅读与六项原版阅读衔接；N3、N2 和衔接材料继续制作，见 [课程实施表](docs/CURRICULUM.md)。[0.19.0 IPA 已发布](https://github.com/CJY-C/jplearn/releases/tag/v0.19.0)，旧版文件继续保留。

## 已实现

- 今天／课程／资料三个入口；可调整每日学习时长。
- SE3 单屏词卡与句型题，底部操作区固定；长文仅在上方独立滚动。
- 实际学习计时、手动暂停、离开及锁屏停止；每日目标按累计时间显示。
- “今天”左上角可看学习统计：累计时间、近 7／30 天趋势和分级的词义、读音、表达、阅读进度；遗忘趋势以 FSRS 预测并单独标明。
- 汉字、注音、中文释义、可选罗马音；系统日语朗读和慢速播放。
- 词义与读音分别复习；每词至少两个语境例句，每个句型至少六个练习。
- 读音揭示后用词组注音和高亮语境加强字音联系；阅读的“假名注音”有独立开关，每篇默认关闭。
- 同形多义词用日语语境区分，词义分别回忆；同一词的追加义项不重复计入词数，字形与可接受读音完全相同才共用认读；新字形仍单独练习。
- 六个假名及音拍诊断，另增三个重音模块（待发布）；多题阅读逐题保存，阶段检测使用日常练习之外的材料。
- [规则与举一反三](docs/RULE_LEARNING.md)（待发布）：数字、月份、日期、钟点、冊，以及动词て／た形、い／な形容词，共七组84题；五个常规数量词项验证后改为按组巩固。活用练转换、还原和句中辨认，原词词义与读音仍分别学习；可推导覆盖与独立词项掌握分开统计。
- 熟悉的规则可手动直接验证，先学时再显示讲解与例外；不会为已有基础强制补做所有词卡。看过讲解的本轮保留辅助标记，仍需不同题组隔天独立复测（待原生验收）。
- 内容保留教材出处、许可与整理状态，新增知识点可查阅教材原文对照。
- 阅读按词义掌握与前置句型筛选，显示实词覆盖率；最后一题提交时保存整篇完成记录，清理排队重复篇目；熟悉篇目逐步延长复习间隔，内容用完即结束（修复待发布）。
- 固定版本 FSRS-6，目标回忆率 90%；使用提示的回答按未独立回忆处理。
- 逐项保存答案；暂停后继续；提交答案与更新位置之间退出也可恢复。
- 课程资料搜索、收藏、笔记；带完整性校验的备份与幂等合并。
- 用户授权的 iCloud Drive 文件夹交换；按事件合并，支持两机离线后汇合。
- GitHub Actions 的内容检查、Swift 单元测试、iOS 集成测试、设备归档和 IPA 打包。
- 每个新版本标签自动构建，全部检查通过后发布带IPA的Release，同时保留Actions artifacts；手动运行可选择只验收，旧版文件保留。

## 通过 GitHub 构建

1. 将项目放入自己的 GitHub 仓库，保留 `.github/workflows/build.yml`。
2. 推送与 `Version.xcconfig` 一致的 `vX.Y.Z` 新版本标签会自动构建，全部检查通过后自动发布Release；普通分支推送和pull request不触发。也可在 **Actions → Validate and build iOS IPA** 中手动运行；手动需要发布时勾选 `publish_release`，只验收时不勾选。
3. 工作流通过后，在 **Releases → 对应版本** 下载 `JPLearn.ipa`；同一次运行的 **Artifacts → JPLearn-提交哈希** 也保留压缩包，解压后取得同一IPA。本机可用 `gh run download <运行编号> -n JPLearn-<完整提交哈希> -D build/downloads/actions-<运行编号>` 下载已有产物，此命令不启动构建。
4. 在已经安装 TrollStore 的兼容设备上打开 IPA 并安装。应用固定 Bundle ID 为 `dev.jplearn.reader`，后续同 ID 更新可保留应用数据。

构建不需要 Apple 开发者证书、Team ID 或仓库签名 secrets。此产物用于 TrollStore；普通系统安装需要另外配置合法签名。

工作流明确使用 macOS 15、Xcode 16.4 和校验过 SHA-256 的 XcodeGen 2.46.0。XcodeGen 从 `project.yml` 生成 Xcode 工程及 Info.plist，SwiftPM 从根目录 `Package.swift` 加载核心模块。FSRS 依赖固定到提交 `4fbaf20184d62f82a9f44f343337c61a2c5483e9`。

应用版本和构建号统一在 `Version.xcconfig` 设置。准备新版本时修改此文件、补充 `CHANGELOG.md` 并完成本地检查，然后推送代码及对应的 `vX.Y.Z` 新标签。自动构建在验证标签与应用版本一致后，执行内容、核心、iOS集成与SE3检查、设备归档和IPA打包，再生成artifact并发布Release。旧标签不移动或覆盖，重复构建不替换已发布文件。手动运行未勾选 `publish_release` 时只保留artifact；日常代码和课程修改不自动升版或创建标签。

版本标签校验的3项本地回归与工作流actionlint检查通过，覆盖标签／应用版本不一致、缺失或重复版本声明和手动分支运行。

## 第一次使用

在“设置”选择学习时长。在系统“辅助功能 → 朗读内容 → 声音”准备日语语音，然后在应用内试播；开启飞行模式再试一次，确认设备已具备离线语音。语音选择只在本机保存。

“今天”从到期复习开始，每天默认引入至多 10 项新词义和 2 个表达；新词义上限可在设置中选择 5–20，包括新词和已有词的新用法。读音与词义独立计分并分开呈现；新义项的可接受读音集合与原词完全相同时，只增加词义练习。遇到较大复习队列时减少新内容。“费力”只用于已经想起的答案，忘记时选“忘记”。

阅读优先安排尚未做过且难度适合的篇目；已读篇目在同一天不再自动安排，再读至少间隔 24 小时。短文要求已会实词占比至少 80%，长文（150 字或 40 个实词以上）至少 95%，并需完成前置表达的自主回忆。0.4.0 的分段长文还逐段检查生词密度，轻松阅读优先要求 98% 覆盖。比例按人工标注的实词出现次数计算，非全文分词覆盖率；词义最近一次自主回忆达到“记得／熟悉”才计为已会，读音记录或使用提示均不算。没有合适的内容时明确结束本轮，时间目标不会触发重复题目。课程页可浏览普通阅读及待学词；阶段检测材料仅在检测入口出现。

计时只在学习页可见、应用前台且未手动暂停时进行。离开学习页、锁屏、进入后台或本轮结束时停止；每 15 秒、提交答案及暂停时保存。做完一轮不会自动算作完成每日时间目标，可以继续下一轮。复习、词语查阅和长文阅读均计入当前学习时间。历史 0.1.0 记录不会补算时间，计时从更新后开始。

在“课程”可查看样章、先查阅讲解，再练习该单元；所有阶段可浏览。“资料”搜索的是已随应用提供的课程内容，不包含完整外部词典。

## iCloud Drive 与备份

1. 在“文件”里创建一个专用的 iCloud Drive 文件夹。
2. 在每台设备的“设置 → iCloud Drive 同步”选择同一个文件夹。
3. 两台设备分别完成练习，再点“现在同步”；等待系统上传下载后，另一台再同步。

本地 Core Data 数据库始终保留在应用容器内；同步文件是带 SHA-256 校验的不可变事件批次。重入前台、每完成 5 项练习以及结束安排时尝试交换。界面显示文件夹交换状态，不把本地写入成功等同于另一台已经收到。iCloud 下载延迟时可稍后再次同步。

此方案不使用应用专属 CloudKit 容器，也不使用 Aidoku 的容器或签名身份。TrollStore 下的目录授权、系统语音和跨设备 iCloud 传输仍需按 [真机验收清单](docs/DEVICE_TESTS.md) 验证。

0.4.0 的备份与同步文件为事件格式 3，兼容导入格式 1、2。新增逐题阅读与诊断结果单独记录。新增学习时间记录随复习记录一同交换；跨设备重叠时段只累计一次。两台设备均须升级到 0.4.0 或以上，旧版无法读取新格式。

“导出学习备份”生成 `.jplearnbackup` 文件，含复习、课程进度、收藏与笔记；“合并备份”保留已有数据、去重相同事件。课程正文随 IPA 提供，备份记录课程版本。请保留独立备份；同步目录里的事件文件属于同步历史。
