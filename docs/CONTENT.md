# 课程制作与验收

## 当前内容和完整路线

`content/` 下的显式 JSON 记录是课程源文件，`scripts/build_content.py` 编译为 `Sources/LearningCore/Resources/foundation.json`。首批包含 31 个单元、323 个词、30 个知识点、319 道词句题、40 篇阅读和 6 个入门诊断模块。详情见 [源文件约定](../content/README.md) 与 [完整课程进度](CURRICULUM.md)。

更高阶段的少量表达可在样章中预览，单元阶段是学习路线的粗分，不表示该单元每一项都属于同一 JLPT 等级。完整路线需继续补齐能力覆盖矩阵：读音、词义与搭配、活用、修饰、授受、敬语、口语、省略、语气和篇章关系。

## 稳定编号和版本

- `v0001...` 为词条，`g001...` 为表达，`s001...` 为句子，`e001a/e001b...` 为练习，`l001...` 为单元，`r001...` 为短文。
- 现有词条按编写顺序获得编号。不能在已有行之前插入或重排；新增词条从末尾追加。大规模制作时应迁移到显式编号的独立 JSON 源文件，保持既有编号不变。
- 文案修正保留编号。学习目标发生实质变化时分配新编号，保留旧记录，不把旧掌握状态强加给新知识。
- 每批内容提升 `version`。更改结构需提升 `schemaVersion` 并先实现迁移或明确拒绝不支持的版本。
- 扩充时先分配原有句子，再追加新句，不挪动原有 `s001...` 的含义。词干与词条的链接保存在显式记录里，不能按前缀猜测，以免将「新」误连到「新聞」。

## 阅读难度与标注

每篇的 `vocabulary` 逐次列出实词原形及 itemID，重复出现的词重复计数。包含名词、动词、形容词和有实义的副词；助词与活用词尾不纳入分母，语法通过 `grammarIDs` 单独约束。未收录词保留 text，itemID 为 null，必须作为生词计入；不能忽略它来抬高比例。每个已链接的注音词都须出现在清单中，自动检查按出现次数核对。标注仍需人工检查漏词及原形映射。

排程将至少 150 字或 40 个实词的材料视为长文，要求 95% 的实词在词义技能中最近一次自主回答达到记得或熟悉；短文阈值为 80%。还限制陌生词种类数量（有段落标注的长文每段最多 3，短文最多 2；旧版未分段材料保留整篇上限），并要求前置句型已自主答对。目录预览显示待学词与前置表达，允许学习者主动阅读尚未自动解锁的材料。

这些阈值是当前材料的产品规则，不代表通用的日语理解保证，也不同于论文中全文词汇覆盖的统计口径。[2025 年词汇覆盖与理解复现实验](https://discovery.ucl.ac.uk/id/eprint/10216385/)发现覆盖率并不能单独解释理解效果，因此不能仅凭比例认定文章适合；还需检查篇幅、句型、语境和实际答题反馈。

## 制作流程

词汇编写源在 `content/authoring/*.tsv`，每条用稳定编号定义：H 明确声明级别，L 为单元，W 为词形、读音、罗马音、义项、词性及两个干扰选项，E 为原创注音例句和中文，A 为有出处的同义读音，D 为作答前的义项提示，N 为揭示答案后显示的用法说明，R 为语体标签。D 不应直接给出本题读音。拼写变体不重复创建为词条；新义项或同形异读不能仅凭字形自动视为已学。结构源同样支持 H；旧源无 H 时保持 N5 兼容，新增 N4–N2 源必须明确声明。

所有源在 `content/manuscripts.json` 注册，用 `python3 scripts/compile_course.py` 统一编译。编译器先从原始和静态批次建立索引，在内存中编译两遍词汇以补齐跨批次链接，再编译结构与阅读；完整替换包通过校验后才写生成文件。旧生成文件中的残留词条不参与索引，注册遗漏或多出的批次会报错。CI 运行 `compile_course.py --check`，只读校验全部已注册源，防止旧链接与当前词库不一致。

整词读音不在本词主读音或同义读音中时，保留为未知；活用词干须显式指定原形，姓名等专名用 `?` 保持未知，语法注音用 `-` 排除出实词统计。字形和读音相同但本词条未教的义项也不能冒用原词链接，例如接电话的出る用未收录义项标注；显式原形和义项仍需逐句语言核对。方法后缀方等语法成分与名词方分开，前置知识在阅读 grammarIDs 中声明。

1. 在阶段覆盖矩阵中选取知识目标，先确认所需的前置词汇和结构。
2. 可用 AI 起草中文讲解、原创例句、初练题和迁移题；禁止将作品未读剧情加入材料。
3. 核对词形、读音、词性、义项和语法适用条件。JMdict、いろどり与 Tae Kim 链接是核对入口，不能因有链接就标记为已审核。
4. 逐句检查日语自然度、人物关系、注音、中文解释和题目是否有唯一正确答案。补充题干未提供的情境，避免将存在歧义的句子硬判为唯一解释。
5. 在两版系统试听常见词和易误读句子。词条朗读使用假名；句子可用 `speechText` 覆盖朗读表记。系统语音不承担音调精确测评。
6. 运行自动检查，个人试用后收集笔记与勘误。需要独立日语审校的内容继续保持 `trial` 状态。

修改后执行：

```sh
python3 scripts/compile_course.py
python3 scripts/build_content.py
python3 scripts/compile_course.py --check
python3 scripts/build_content.py --check
python3 -m unittest discover -s Tests/ContentTests -v
```

自动检查验证编号、引用、题目、注音完整性、数量和生成一致性。日语自然度、释义准确性与题目教学效果仍需语言核对和实际试用。

## 材料与来源

当前中文说明、短文与练习为本项目编写的试用材料，没有打包商业教材或作品原文。每项保留核对资料入口和状态；后续引入外部词典或音频数据时，记录明确的数据来源、授权和署名要求。不要把仅英文释义的数据误称为完整日中词典。
