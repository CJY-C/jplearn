# 真机验收清单

这些检查尚未执行。分别记录 iOS 15.5 与 16.6 的设备型号、TrollStore 版本、IPA commit、结果及复现步骤。模拟器的测试通过不能代替真机验收。

## 安装与离线

- 从 GitHub Release 取得 IPA，在两版设备安装、首次启动、强制退出并重启。
- 检查三个入口、应用图标、课程与资料搜索均可用。
- 准备日语语音后进入飞行模式；检查词语朗读、句子朗读、慢速和结束后的音频恢复。
- 飞行模式完成词义、读音、结构、新句和短文练习，再退出重开，核对记录与继续位置。
- 在揭示答案前输入正确、错误、全角片假名、半角片假名和错误长音，检查判定。
- 使用提示或输入错误后，不应记录为独立回忆成功。
- 使用提示后尚未作答就暂停或重启，继续后仍按辅助回答记录。
- 选择题选定答案、尚未点击“继续”就退出，恢复后答案仍在，且不重复计数。

## 数据与更新

- 答完一项立即结束进程，重新进入后没有重复计数或丢失已提交答案。
- 暂停一半后继续；提前结束后可以重新安排；全部做完后单元显示完成。
- 收藏、取消收藏、写笔记、清空笔记；导出备份并重复导入两次，记录数量不重复增加。
- 先导出旧备份，再清空笔记和取消收藏；合并旧备份，旧内容不应复活。
- 同 Bundle ID 安装更新版 IPA，复习、收藏和笔记应保留。
- 在备份副本里破坏字节再导入，应明确失败且保留本地记录。

## 两机 iCloud Drive

- 使用同一个 iCloud 账号，两台设备各自通过系统选择器授权同一专用目录。
- A 完成几项，手动同步；等待文件上传后 B 同步，核对记录。
- A、B 同时断网，各复习同一个词，分别重连，多次交换后两边记录数和到期状态一致。
- 重复同步不新增重复记录；收藏取消、笔记清空也应跨设备传播。
- iCloud 文件被系统移除本地下载后，同步显示等待下载，稍后可成功重试。
- 修改目录位置、撤销授权或关闭 iCloud Drive；应用应保留离线学习，显示同步未完成，可重新选目录。
- 同步进行时继续回答题目，结束后核对新答案仍然存在。
- 同步过程中断网、切后台、重启，确认原有文件完整、事件可再次交换。

## 界面与语言

- 小屏幕、iPad、横屏、大号辅助字体和深色模式下，注音不裁切，按钮可操作。
- VoiceOver 可以读到例句，通过“本句词语”菜单访问词汇解释。
- 试听多音字、促音、长音、拗音和敬语；核对系统语音的实际读法，记录需要 speechText 修订的句子。
- 选取未练过的句段，检查是否能减少提示并理解结构；记录难度不合适的材料，修订课程排序。

## SE3 与实际学习时间

- 375×667 标准字号下，首页开始按钮、词卡揭示、四个评分、句型选项和继续按钮无需上下滑动即可操作。
- 假名键盘打开后，检查答案仍可见；提交后键盘收起，不遮挡下一步。
- 长文仅上方正文滚动；下方问题、选项和继续按钮不随正文移动。
- 学习 30 秒，暂停、锁屏或切到后台 30 秒，再回到学习；累计时间只增加实际学习部分。
- 暂停后切后台再回来，保持暂停，直到手动继续；离开学习页后首页不继续计时。
- 做完一轮但未达到目标时显示本轮完成；继续下一轮后每日时间接着累计。
- 备份恢复、重复合并及两机同步后，时间不重复增加；跨午夜的学习按两天分别累计。

## 排程与阅读负担

- 连续完成多轮后不再循环“去图书馆”；同一篇今天只自动出现一次，跨午夜未满 24 小时也不重排。
- 今日可安排内容耗尽后显示完成，不能靠重复同一道题填满时间目标；课程仍可主动查阅。
- 从 0.2.0 覆盖更新，正在重复的阅读会被跳过，原计时、笔记和复习记录保留。
- 只有读音回答、提示或错误词义答案时，阅读覆盖率不把该词算作已会；自主答对词义后比例相应增加。
- 长文未达到 95% 实词覆盖或缺少前置句型时不自动安排；课程预览仍显示待学词与表达。
- 新词设置为 5、10、20 后连续开始多轮，当日新词数分别不超过设置；复习不受新词上限影响。

## 0.4.0 课程首批

- 入门的五题诊断可以在 SE3 上完成，结束后显示检查结果；首页练习数不因诊断增加。
- 多题阅读在同一页面切换下方题目，上方滚动位置保留；选答案后立即退出再打开，可以继续后续题目。
- 最后一题答完、尚未点击继续就退出，重开后只记录一次整篇结果。
- 阶段检测在日常阅读及正文预览中不可见；检测后能查看原文、各题答案和证据。
- 从 0.3.0 覆盖安装，已有词语、笔记、收藏、计时和安排保持；两台设备都升级后再验证格式 3 同步。
- 保存包含新题目记录的独立备份。旧版应用不能读取格式 3 或包含新事件类型的本地记录，不将旧版本覆盖视为无损降级。
