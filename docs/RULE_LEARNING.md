# 规则、例外与迁移练习

可推导的表达先学规则和适用条件，再换实例验证。用户不需要把每个组合背成独立单词，也不会仅因看过规则就获得整组掌握记录。

## 第一批已接入内容

| 单元 | 归纳范围 | 保留的边界和例外 |
| --- | --- | --- |
| 数字组合 | 0–99整数，十位与个位组合 | 四／七／九的选读；号码逐位读不同；百、千另学 |
| 月份 | 数字＋がつ | 四、七、九月；月份与持续几个月不同 |
| 每月日期 | 常规数字＋にち | 1–10、14、20、24日；17／27、19／29的基本选读；一号与一天 |
| 钟点 | 1–12点，数字＋じ | 四、七、九点；钟点与时长不同；分钟音变另学 |
| 冊 | 成册物与数量 | 一、八、十的基本音变；冊与本的计数对象不同 |

各有三个四题题组，共60题。题组混合组合、特殊读法、含义与使用边界；不计入词汇根、句型功能或篇章检测数量，也不用来补足N2配额。假名读法不用于生成未经核对的重音。材料未经过独立日语审校。

## 调度与证据

1. 初次显示规则、组合例子及例外；之后自动复测直接出题，可主动查看规则。
2. 每题即时保存。查看规则使本轮变成辅助作答，答对也不算独立通过。
3. 一组四题全部独立正确才能通过。至少两个不同题组通过且相隔满24小时，才标为「已验证迁移」。只有passed标记、缺少逐题答案、答案与正确标记冲突都不能提供迁移证据。
4. 每轮安排最多一组规则题，轮换最久未做的题组。同一规则至少隔24小时；多个不同规则可在同一天学习。失败后需要再次验证，避免立即循环刷同一组。
5. 复测间隔依隔天的连续成功次数设为1、3、7、14、30天，失败回到1天；同一天加练不增长间隔。未完成迁移验证时保持次日复测。这是待验证的产品默认值，**不是FSRS估计或实测遗忘曲线**。轮换有限题库不等于每次都能提供未见题。
6. 验证后，作者明确列出的常规词项不再单独占用自动新词和到期卡，改为整组规则复测。第一批仅合并五个旧常规词项（一／六／十時，二／三冊）。基础数字、日期特殊词项、时长、词汇化表达、多义词全部保留；禁止按前缀批量匹配。
7. 某个词项的能力随后遗忘或使用辅助，该能力恢复独立练习；整组检测失败则取消整组合并，重新验证。手动进入相关词汇单元也提供规则练习。

新用户先完成数字组合练习，或已有一到十的独立字音与词义记录，才开始其他规则。初次规则通过可解锁后续规则，**不等于基础数字词卡已全部掌握**。

## 统计、阅读与兼容

独立词义／读音进度只来自实际词项复习。统计另列「规则迁移」。阅读覆盖可计入经验证的可推导表达，同时单列其出现次数；不把它们显示为独立掌握词数。专名、其他义项和特殊读法不借用规则掌握。合并后的词项不再显示单独FSRS遗忘预测，避免把整组练习误作单词级调度证据；旧词项记录和练过的数量仍保留。

阅读可声明前置规则及具体例外题。例如“四月三日”使用已学数字、月份规则和已教“三日”组合，不创建整个日期的新词根；自动安排前须验证月份规则，并有“四月”特殊读法所在题组的完整独立通过记录。通过其他月份题组不等于通过四月；查看规则、缺题、只有完成标记均不能提供例外证据。完整题组失败后，迁移及例外确认一起重置。预览会显示需复测的规则名称，词汇覆盖达到100%也不绕过这一条件。

规则题组结算后重新筛选当前队列中的阅读；复测失败时移除已不满足前置的篇目，保留已提交记录与后续词卡。对应AppModel集成检查已加入，仍需在macOS/iOS执行。

阅读稿件用`D`记录声明规则与例外题，编译及客户端校验引用归属、重复与缺失；旧阅读没有该字段时保持原行为。规则和例外证据均从既有事件重建，无需迁移备份格式。

沿用questionAttempt保存选择、placement保存题组结果；不新增事件类型或伪造FSRS词项记录，备份／iCloud事件格式保持3。旧课程包没有learningRules也可解码；旧词句、答案、顺序及编号保留。新增的rule学习安排需要新版客户端；旧客户端不能恢复这个新任务时仍保留历史并提示重新安排。

界面沿用原生按钮与StudyCardLayout：长讲解在上部滚动，答案和继续按钮固定，题目在原页推进。SE3大小字号、逐题恢复、辅助标记的iOS检查已补充，需在macOS/iOS运行；Linux核心检查不替代真机验收。

## 后续扩展原则

| 内容 | 可以归纳 | 仍需区分 |
| --- | --- | --- |
| 人、时长、其他助数词 | 单位含义＋选读与音变 | 一人／二人／四人，ふん／ぷん，适用对象 |
| 动词活用 | 活用类别＋词干＋转换，换动词练习 | 行く的て形，する／来る；以る结尾不一定是一段 |
| 形容词 | い／な类的否定、过去与连接 | いい→よく；きれい不是い形容词 |
| 能产接辞 | ～方、～さ、～的的条件与组合 | 固定搭配、词汇化、多义及不自然搭配 |
| 敬语 | 人物关系、主体、受益方向的模型 | 专用形式、身份关系与场景判断 |
| 汉字构词 | 音读系列提供线索，换词辨认 | 熟字训、音训切换、连浊、同字异读及词义漂移 |

原定N5–N2内容目标继续执行，不扩造规则组合词凑数量，也不以规则替代词汇、阅读和敬语训练。

## 来源与适用限度

- [JPF《あきこと友だち2》文法解説](https://ba.jpf.go.jp/wp-content/uploads/2022/03/Akiko2_bunpoo382002.pdf)：第6课数字及助数词、第7课年月日；日期和月份表还通过PDF图像核对。中文讲解、情境与问题为项目编写。
- [JPF《まるごと》入门A1文法解説](https://md.jpf.go.jp/userfiles/file/2018/Lengua%20Japonesa/Gramatica/A1-JP_rev.pdf)：印刷p.32–35，钟点、时长及七点的传话选读。
- [2024：Far transfer of retrieval-practice benefits](https://link.springer.com/article/10.1186/s41235-024-00598-y)：人工语法实验支持提取练习与延迟保持、迁移的联系，不能保证每位用户的日语学习提速。
- [2025：Whether Interleaving or Blocking Is More Effective for Long-Term Learning Depends on One’s Learning Strategy](https://pmc.ncbi.nlm.nih.gov/articles/PMC12108632/)：分类实验中练习顺序的优势随学习策略改变。本项目采用先集中理解规则，再混合辨析和延迟检验的设计假设，不声称实验直接证明本应用效果。
