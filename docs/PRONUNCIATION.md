# 发音、重音与朗读

日语重音作为可看、可练的教学内容，不以 TTS 能否正确演示为前提。当前工作分支新增三个入门模块：拍与下降点、助词接续与四类参考型、词重音与句子语调，共十五道标记理解题。它们检查标记与概念，不是听辨或发声评分；完成诊断不产生词义、假名读音或发声掌握记录。

用 `↓` 标出第几拍后下降，`[0]` 表示没有词汇性下降，避免把“平板”教成整句从头到尾一个音高。比如 `はなが [0]`（鼻）与 `はな↓が [2]`（花）可以在助词连接处看出差别。整句语调、疑问和焦点仍需在语境中学习，不能把每个单独词的固定高低图原样拼成整句。这一设计参考[国際交流基金 2025 年的教学说明](https://www.jpf.go.jp/j/project/japanese/teach/tsushin/research/202503.html)以及[东京外国語大学的发音模块](https://www.coelang.tufs.ac.jp/mt/ja/pmod/practical/01-08-01.php)，中文、题目与显示组件另行编写。

[发音编写源](../content/pronunciation.json)目前只给雨、飴、花、鼻、箸、あなた、湖、夏休み八个词添加有明确来源的东京式参考型，包括假名、显式分拍、下降位置和出处。词汇详情可查看，练习中在揭示答案后显示紧凑标记。未核对的词显示“重音：待核对”，没有标注不等于 `[0]`。这里的资料核对不代替独立日语审校，也不表明其他方言的发音有误。[核对范围及后续工作](../content/source-checks/pronunciation-foundations.json)明确列出实际取得的来源。

朗读使用苹果的设备语音。自动模式优先使用已可用的高品质日语声音，手动选择仍优先；原声音被移除或不属于日语时回退到可用日语声音。iOS 15.5 使用其可用的基础／增强声音，premium API 仅在 iOS 16 及以后访问，具体日语声音是否存在由设备决定。从系统下载声音后返回应用会刷新选择。入门讲解、词语和例句使用同一声音偏好；普通、慢速播放仍保留。

高音质不等于每个词义和句子的重音都已核对。新重音模块不播放未经听审的合成示范，也不将箭头、数字读作示范音频。文字输入反馈称“假名读音正确”，不把键盘答案当作实际发音评分。苹果的声音质量、可用声音枚举和系统语音下载见[开发文档](https://developer.apple.com/documentation/avfaudio/avspeechsynthesisvoicequality)、[系统支持说明](https://support.apple.com/en-in/111798)。

接下来随 N5–N2 内容逐步扩充词义、读音变体、活用及复合形式的重音核对和上下文练习；八个参考词不算完整词库覆盖。经核对的听辨材料、独立重音复习与进度记录仍待实现，不用 TTS 预测自动填齐。所有旧词义、读音、答案、阅读、顺序和事件格式保留，本次只增添可选重音字段与三个入门模块。

本地已通过 27 项相关核心测试（包括不同字形的认读归属）；iOS 语义编译、设备声音试听和 SE3 布局仍待验证。当前尚无包含这些改动的新 IPA。
